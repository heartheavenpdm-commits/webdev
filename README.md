# Pink Cat Student Portfolio

A responsive student portfolio designed with a pastel pink + cat aesthetic and glassmorphism.

## Files

- `index.html` — portfolio structure and content
- `style.css` — responsive glassmorphism design
- `script.js` — mobile menu, active navigation, and dark mode
- `images/cat.webp` — profile image supplied by the user
- `images/flower.jpg` — portfolio background supplied by the user

## Deploy to Vercel

1. Upload this folder to a GitHub repository.
2. Open Vercel and import the repository.
3. Framework Preset: **Other**
4. Build Command: leave blank.
5. Output Directory: leave blank.
6. Deploy.

Or use the Vercel CLI from the project folder:

```bash
vercel
```

## Before submission

Replace:
- `Your Name`
- `Your University / College`
- `student@example.com`
- GitHub and LinkedIn `#` links
- project `#` links

The portfolio is intentionally static, so no database or backend is required.
